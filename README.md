# 💰 Sistema Bancário em Python

Este é um projeto simples de sistema bancário desenvolvido em Python para fins educacionais.

## Funcionalidades

- Depósito (somente valores positivos)
- Saque (máximo de R$ 500,00 por saque, até 3 saques por dia)
- Extrato com listagem de operações e saldo atual

## Estrutura dos Arquivos

- `main.py` — Arquivo principal com o menu de interação
- `deposito.py` — Função de depósito
- `saque.py` — Função de saque
- `extrato.py` — Função de extrato
- `utils.py` — Constantes usadas no sistema

## Como executar

1. Clone ou baixe este repositório
2. Navegue até a pasta do projeto
3. Execute com:

```bash
python main.py
```
